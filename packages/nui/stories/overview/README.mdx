## Character ✨

- **Modern Design** – Follows the shadcn-ui design language specification
- **Dark Mode** – Built-in dark mode support
- **Theme Customization** – Supports theme configuration via [Tweakcn-Editor](https://tweakcn.com/editor/theme)

## Getting Started

- **Installation** – Follow the [installation guide](./installation.mdx) to add @nw/ui to your project
- **Development** – Follow the [development guide](./development.mdx) to set up your local development environment and contribute to @nw/ui
- **Component Overview** – Explore the [component overview](./index.mdx) to see all available components and their usage
