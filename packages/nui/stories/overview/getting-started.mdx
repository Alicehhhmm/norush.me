# Getting Started

### Prerequisites

- **Node.js** >= 18.0.0
- **React** >= 18.0.0
- **React DOM** >= 18.0.0
- **TypeScript** >= 5.5.0

## Setup

### pnpm

```bash
pnpm add @nw/ui
```

## Configuration

### NextJS

```tsx
// Global Styles
import 'tailwindcss';
import '@nw/ui/styles';
```

```tsx
// page
import { Button } from '@nw/ui';
export default function Page() {
  return (
    <div>
      <Button>Hello World</Button>
    </div>
  );
}
```
