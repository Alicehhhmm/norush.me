# 快速开始

本指南将帮助你快速开始使用 @nw/ui 组件库。

## 📋 前置要求

在开始之前，请确保你的项目满足以下要求：

- **Node.js** >= 18.0.0
- **React** >= 18.0.0
- **React DOM** >= 18.0.0
- **TypeScript** >= 4.5.0 (推荐)

## 📦 安装

### 使用 pnpm（推荐）

```bash
pnpm add @nw/ui
```

### 使用 npm

```bash
npm install @nw/ui
```

### 使用 yarn

```bash
yarn add @nw/ui
```

## ⚙️ 配置

### 1. 导入样式

在你的应用入口文件中导入一次全局样式：

```tsx
// src/main.tsx 或 src/index.tsx
import '@nw/ui/styles';
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

### 2. 配置 Tailwind CSS（可选）

如果你需要在项目中使用 Tailwind CSS 的 utility classes，请确保你的 `tailwind.config.js` 包含以下内容：

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    './src/**/*.{js,jsx,ts,tsx}',
    './node_modules/@nw/ui/dist/**/*.{js,jsx,ts,tsx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
};
```

## 🎯 基础用法

### 第一个组件

```tsx
import { Button } from '@nw/ui';

function App() {
  return (
    <div>
      <h1>Welcome to @nw/ui</h1>
      <Button>Click Me</Button>
    </div>
  );
}
```

### 使用不同变体

```tsx
import { Button } from '@nw/ui';

function App() {
  return (
    <div style={{ display: 'flex', gap: '8px' }}>
      <Button variant="default">Default</Button>
      <Button variant="primary">Primary</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="link">Link</Button>
    </div>
  );
}
```

### 使用不同尺寸

```tsx
import { Button } from '@nw/ui';

function App() {
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}>
      <Button size="sm">Small</Button>
      <Button size="default">Default</Button>
      <Button size="lg">Large</Button>
      <Button size="icon">🔍</Button>
    </div>
  );
}
```

## 🎨 深色模式

@nw/ui 内置了深色模式支持。

### 启用深色模式

```tsx
function ThemeToggle() {
  const [isDark, setIsDark] = React.useState(false);

  const toggleTheme = () => {
    document.documentElement.classList.toggle('dark');
    setIsDark(!isDark);
  };

  return (
    <Button onClick={toggleTheme}>{isDark ? '☀️ Light' : '🌙 Dark'}</Button>
  );
}
```

### 自动检测系统主题

```tsx
React.useEffect(() => {
  const isDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  if (isDark) {
    document.documentElement.classList.add('dark');
  }
}, []);
```

## 🔧 TypeScript 配置

确保你的 `tsconfig.json` 包含以下配置：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["DOM", "DOM.Iterable", "ES2020"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

## 📱 响应式设计

所有 @nw/ui 组件都支持响应式设计：

```tsx
import { Button } from '@nw/ui';

function ResponsiveExample() {
  return (
    <div>
      <Button className="w-full sm:w-auto">Responsive Button</Button>
    </div>
  );
}
```
