# @nw/ui

基于 React + TypeScript + Tailwind CSS v4 的 UI 组件库。

## Command

```bash
pnpm dev              # 开发模式
pnpm build            # 构建
pnpm storybook        # Storybook (http://localhost:6006)
pnpm test             # 测试
pnpm lint             # 代码检查
pnpm lint:types       # 类型检查
pnpm clean            # 清理
```
