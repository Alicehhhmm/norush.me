## How to Contribute to the Changelog

This changelog is automatically generated based on changeset files in the `.changeset` directory. To add a change:

1. Run `pnpm changeset` to create a new changeset file
2. Describe your changes and select the appropriate version bump (major, minor, patch)
3. Submit a pull request with your changes

For more information, see the [Changesets documentation](https://github.com/changesets/changesets).
